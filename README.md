# Auto-Ticket-Classification-using-Flow-Designer
Automatically classifies and routes service tickets using Flow Designer based on ticket details, reducing manual effort and improving ticket management.
## Project Overview

 **Auto Ticket Classification using Flow Designer** is a ServiceNow-based automation project designed to simplify and automate the process of handling support tickets. When a new ticket is created, the system analyzes the ticket details such as **short description, category, priority, and issue type**.

 Using **Flow Designer**, predefined conditions are applied to automatically classify the ticket and assign it to the appropriate **assignment group**. The flow can also update priority, category, and other required fields and notify the responsible team.

 ### Main Objectives

 - Automate ticket classification.
- Reduce manual effort and human errors.
- Route tickets to the correct support team.
- Improve ticket response and resolution time.
- Maintain consistent ticket categorization.

 ### Working Process

 **Ticket Created → Flow Triggered → Ticket Details Checked → Category/Priority Identified → Assignment Group Selected → Ticket Updated → Team Notified**

 ### Technologies Used

 - ServiceNow
- Flow Designer
- Incident Management
- Flow Actions
- Conditions and Decision Logic

 ### Expected Outcome

 The project provides a faster and more organized ticket management process by automatically classifying and routing tickets, allowing support teams to focus more on resolving issues rather than manually processing tickets.
